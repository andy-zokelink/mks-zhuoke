起源 · 1936–1958
理论基石
1936
图灵机：一切计算的起点。24岁的图灵证明了——理论上，机器可以模拟任何思维过程。
等了78年才被AlphaGo部分回答
图灵解决的是一个哲学问题：什么是"可计算的"？他证明了存在一种通用机器可以执行任何可计算的任务。AI最深层的种子就此埋下——如果思维可以被还原为计算，机器就能思考。
火种年代 →
理论基石
1943
麦卡洛克-皮茨：第一次用数学语言描述神经元。证明神经网络可以计算任何函数——这是AI的"元细胞"。
影响了从冯·诺依曼到辛顿的两代人
一个神经元什么也做不了。1000亿个神经元就是人类大脑。这篇论文把生物学转化为数学——这就是"涌现"最原始的版本。
火种年代 →
历史节点
1950
图灵测试："机器能思考吗？"——一个绕过了所有哲学家的天才问题。
72年后被ChatGPT用"文字接龙"回答了
图灵没有试图定义"思考"，而是设计了一个可操作的测试。70多年后，当人们与ChatGPT对话时，他们发现自己无法分辨对方是人还是机器。
火种年代 →
历史节点
1956
达特茅斯会议：AI的命名礼。最聪明的人相信"一个夏天"就能解决机器翻译和视觉。他们错了——晚了60年。
乐观预测全部实现，只是晚了40-60年
麦卡锡、明斯基、香农、罗切斯特——一群天才在达特茅斯学院度过了一个夏天。"人工智能"这个名字被正式提出。泡沫与幻灭，是AI成长的必修课。
火种年代 →
理论基石
1958
感知机：第一个"能学习"的机器。400个光传感器，通过试错识别字母。神经网络有了第一个物理化身。
11年后被明斯基的《感知机》"杀死"
媒体狂喜："海军期待一台能走、能说、能看、能写的机器。"期待远超现实。感知机只能处理线性可分问题——这个局限，明斯基在1969年用数学严格证明了。
火种年代 →
寒冬 · 1969–1986
历史节点
1969–80
第一次AI寒冬：政府资助骤减，研究者被迫改名换姓。但辛顿、杨立昆、本吉奥在寒冷中继续坚守。
三个人在寒冬坚持，30年后分享了图灵奖
英国政府报告结论是"AI在任何领域都没有产生预期影响"。DARPA大幅削减资助。冬天不是结束，只是种子的休眠。
火种年代 →
理论基石
1986
反向传播：让多层网络"从错误中学习"。1974年就被沃伯斯提出，被埋没了12年——不是因为理论错了，是算力没到。
被埋没12年，又等了26年才全面爆发
思想出奇简单：网络前向计算输出，与答案比较得出误差，把误差反向传播回去调整权重。就像投篮——投出去，看到偏了多少，回来调整力度和角度。但1986年的计算机根本跑不动。
苏醒 →
复兴 · 1997–2012
历史节点
1997
深蓝击败卡斯帕罗夫。每秒评估2亿个局面——用的不是"学习"，是暴力搜索。但全世界第一次被迫面对：机器能在"智慧皇冠"上击败人类。
每秒2亿个局面 vs 人类直觉
卡斯帕罗夫输掉后提出了"人+机器"的合作模式——不是人与AI对抗，而是人与AI配合。这个洞见比当时任何技术评论都更深刻。
苏醒 →
理论基石
2006
辛顿发表深度信念网络。此时距他进入这个领域已经34年——被无数人告知"神经网络没有前途"。
34年的坚守，换来一场革命
辛顿从30多岁起就无法坐下，必须站着工作。他的博士导师告诫他放弃。整个学术界视神经网络为死路。但他坚持了下来。又等了6年，直到AlexNet，世界才真正相信他是对的。
苏醒 →
涌现时刻
2012
AlexNet：AI的"iPhone时刻"。错误率从25%骤降到16%。整个计算机视觉界一夜之间转向深度学习。GPU + ImageNet + 辛顿 = 爆炸。
错误率 25% → 16%，一夜之间的革命
两个关键因素：GPU——游戏显卡意外成为深度学习引擎；ImageNet——1400万张标注图像。AlexNet的作者之一伊利亚·苏茨克维，后来成为OpenAI首席科学家，主导了GPT系列的开发。
苏醒 →
历史节点
2016
AlphaGo第37手——人类几千年围棋史中从未出现过的一步棋。AI不需要人类的"知识"来超越人类。
AlphaGo Zero 3天超越击败李世石时的版本
AlphaGo Zero不再需要人类棋谱，只通过自己和自己下棋。从零开始，只靠规则和试错，发现了人类从未想到的策略。这个思想后来被DeepSeek R1发扬光大。
涌现 →
爆发 · 2017–2023
理论基石
2017
《Attention is All You Need》——8位背景各异的年轻人在谷歌走廊上的讨论，改写了AI的全部未来。这篇论文是所有现代大语言模型的祖先。
8位作者，1篇论文，改变了世界
核心思想"自注意力机制"最初被所有人反对——包括提出者老四的爸爸。但伊利亚看到论文第一天就理解了它的含金量，立刻停掉OpenAI所有项目，全力开发GPT-2。谷歌高管后来懊悔："如果当年重视Transformer，我们2019年就做出GPT-3.5了。"
涌现 →
涌现时刻
2020
GPT-3：1750亿参数。没有人教它推理，它自己学会了。这就是"涌现"——参数超过阈值，能力突然蹦出来。
1,750亿参数 · 涌现的降临
GPT-3展现的涌现能力——算术推理、语言翻译、代码生成——不是被设计进去的，是自己"冒"出来的。就像生命游戏中4条简单规则能产生滑翔机。"缩放定律"成为新圣经：不需要更聪明的算法，只需要更大的模型。"大力出奇迹"。
涌现 →
涌现时刻
2022
ChatGPT：一个聊天框，改变了世界。2个月1亿用户——史上增长最快。AI从实验室走进了每个人的手机。
2个月 · 1亿用户 · 史上最快
OpenAI最初只是想做一个"展示RLHF技术"的demo。没有人预料到它会成为历史上增长最快的消费产品。一个聊天框——这个看似简单的交互改变，让AI从"工具"变成了"对话者"。
涌现 →
裂变 · 2024–2025
理论基石
2024
诺贝尔物理学奖和化学奖同时颁给AI。最保守的学术机构承认了AI——不是工程成就，是科学范式的转变。
52年等待 · 最高荣誉
物理学奖颁给了霍普菲尔德和辛顿——神经网络根植于统计物理的深厚土壤。化学奖颁给了AlphaFold——解决了困扰生物学50年的蛋白质折叠问题，2.14亿个蛋白质结构一次性公开。
裂变 →
涌现时刻
2025
DeepSeek R1：十分之一的成本，接近GPT-4o的性能，完全开源。在芯片受限的情况下，深入底层用PTX直接编程GPU来创造奇迹。
成本 1/10 · 性能接近 · 完全开源
在资源受限中爆发了更强的创新：DualPipe技术优化计算与通信并行，RL微调让数学能力从100分提升到450分。杨立昆说："这不是两国AI谁超过谁的问题，而是开源战胜了专有。"
裂变 →
门槛 · 此刻 →
涌现时刻
此刻
AGI的门槛：缩放定律已达极限。下一个突破不会来自"更大的模型"，而会来自"更聪明的架构"。我们既是观察者，也是参与者。
1936 → 此刻 → AGI：90年的接力
DeepMind创始人预测AGI均值年份是2028年。伊利亚说"缩放定律已经结束了"。人类这个物种最伟大的地方，不是创造了智能，而是创造了一种可以创造智能的智能。
